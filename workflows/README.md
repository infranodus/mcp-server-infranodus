# FirstMile Workflows Directory

## Ready-to-Use Workflow Templates for InfraNodus

This directory contains step-by-step workflow templates for using InfraNodus in your FirstMile business operations.

---

## Available Workflows

### 1. Discovery Call Analysis
**File:** `discovery-call-analysis.md`

**Use When:**
- After every discovery call
- Before writing follow-up emails
- Preparing proposals

**What It Does:**
- Reveals hidden pain points
- Identifies content gaps in conversation
- Generates strategic follow-up questions
- Positions FirstMile strategically vs tactically

**Time Required:** 5-10 minutes per call

**Expected Impact:**
- 40% more strategic questions per call
- 15-20% higher conversion rate
- 50% better follow-up engagement

---

## Workflow Structure

Each workflow includes:

1. **Objective** - What you're trying to achieve
2. **When to Use** - Specific triggers/situations
3. **Required Tools** - Which InfraNodus tools you'll need
4. **Step-by-Step Process** - Detailed instructions with prompts
5. **Output & Action** - What to do with the results
6. **Success Metrics** - How to measure impact
7. **Real Examples** - Actual use cases and results
8. **Templates** - Copy-paste email/proposal templates

---

## Quick Start

### First Time Using Workflows?

1. **Start with Discovery Call Analysis**
   - Easiest to implement
   - Immediate ROI
   - Builds foundation for other workflows

2. **Pick a Real Discovery Call**
   - Use an actual recent call (not a test)
   - Full transcript or detailed notes
   - Better results with more detail

3. **Follow the Template Exactly**
   - Copy the prompts verbatim first
   - Understand the pattern
   - Customize later

4. **Measure Results**
   - Track follow-up response rate
   - Note prospect engagement
   - Compare to non-InfraNodus calls

## Creating Your Own Workflows

### Workflow Template Structure

```markdown
# [Workflow Name]

## Objective
[What you're trying to achieve]

## When to Use
- Specific trigger 1
- Specific trigger 2

## Required Tools
- tool_name_1
- tool_name_2

## Step-by-Step Process

### Step 1: [Action]
**Prompt Template:**
```
[Exact prompt to use]
```

**Tool Used:** `tool_name`

**Expected Output:**
[What to expect]

[Repeat for each step]

## Output & Action
[What to do with results]

## Success Metrics
[How to measure]

## Real Example
[Actual use case]
```

## Best Practices

### 1. Use Consistent Naming
```
discovery-[company]-[YYYY-MM-DD]
competitor-[name]-[quarter]
seo-[topic]-[month]
pipeline-patterns-[period]
```

### 2. Save Important Graphs
Use `create_knowledge_graph` (not just analyze) for:
- Discovery calls (proposal reference)
- Competitive intelligence (ongoing tracking)
- Pipeline patterns (training materials)

### 3. Build Libraries
Organize by type:
- All discovery calls
- All competitive analyses
- All SEO research
- All pipeline patterns

### 4. Iterate and Improve
- Track what works
- Refine prompts
- Customize templates
- Share wins with team
